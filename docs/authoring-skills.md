# 创建、调用和同步共享技能

## 路由与创建

`agent-shared-skills` 先扫描当前技能，比较目标、触发边界和原生能力。相同能力优先复用或局部扩展，有独立且可重复的用途时才创建。项目专属技能可写明“需要时读取共享技能 `<name>` 的 SKILL.md”，由当前 Agent 解析真实位置；不复制正文形成第二个维护来源。

## 最小目录

```text
.agents/skills/example-skill/
  SKILL.md
  references/SETUP.md   # 有专用依赖时提供
  scripts/             # 必要的小脚本；不放虚拟环境或程序安装包
```

SKILL.md 至少包括 frontmatter 的 `name`（与文件夹相同）、`description`（何时调用），以及用途、输入、步骤、边界和验收。安装说明可内联；若独立成文件，必须从入口以相对链接到达。第三方正文保持来源关系，本地说明放 local/ADAPTATION.md 并有读取入口。

## 可复制模板

````markdown
---
name: example-skill
description: 当用户需要处理某类明确任务时使用；列出必要触发条件。
---
# 示例技能

## 用途与边界
说明何时使用、何时不用。

## 输入与步骤
说明需要的输入、执行步骤、停止或转交条件。

## 本机准备
说明纯方法 / Skill＋CLI / Skill＋MCP / API / 原生能力。
有专用依赖时，读取 [安装说明](references/SETUP.md)。

## 验证
执行一个最小真实任务，说明结果与失败处理。
````

## 三类依赖

| 类型 | 同步内容 | 本机准备 | 验证 |
|---|---|---|---|
| 纯方法 | 步骤、模板、判断规则 | 当前 Agent 能力 | 最小任务 |
| Skill＋CLI | 技能、脚本、版本及安装说明 | 当前系统的 CLI/运行时 | 版本＋真实命令 |
| Skill＋MCP | 技能、登记模板及安装说明 | 服务、Agent 配置、认证 | 当前 Agent 工具调用 |

安装说明必须列出必需和可选项、检测命令、官方安装入口、版本要求、当前平台分支、人工登录步骤和成功判据。WSL 与 Windows 分开；独立 Linux 按发行版准备。无法验证的平台明确写未验证，不编造安装方法。

## 新电脑第一次使用

文件同步 → 补齐当前 Agent 技能入口 → 读取 SKILL.md 及安装说明 → 检查本机依赖 → 在授权内准备所需能力 → 执行最小任务。其他电脑曾运行成功，不证明当前电脑已就绪。

不要批量安装所有扩展的工具。调用具体技能时才检查它的依赖；密钥、程序、缓存和 live MCP 配置留在本机。

## 同步新增技能

先预览并应用安装入口，或用核心 skill sync helper 限定 Agent 与技能。逐技能链接不会自动发现同步目录中所有新增文件夹；新增或改名后需要补齐本机链接，并按客户端要求重载技能。

从 examples/ 中选择纯方法或 Git CLI 示例，复制到共享 skills 目录前查看差异并确认作用范围。示例不会由核心安装器自动安装。
