# 可选扩展

首版只自带四项核心治理能力。下载框架不等于安装所有业务 CLI、模型、MCP 或 Agent。

## 添加一个扩展

从作者官方来源核对许可证和固定版本，在共享源外审阅。通过 agent-shared-skills 比较已有能力；确认后把必要说明、脚本与资源放入共享 skills，保留原版权，补齐当前平台安装说明。再在各机补齐技能入口并实际验证。没有明确再分发许可的内容只提供来源，不打包。

## REA：Skill＋本机 CLI＋可选 MCP

REA 为可选示例，不是核心前置依赖。[上游仓库](https://github.com/morluto/rea) 的安装说明是程序与技能的来源；不把本项目的路由说明当作上游安装器。按所选版本检查 Node、安装 CLI、运行 `rea --version`。仅需要当前版本真实支持的分析引擎时才准备它们。

`.agents/mcp/catalog/rea.json` 提供跨系统启动意图。先通过本机命令解析检查，使用 agent-shared-mcps 对选定 Agent 预览；配置后重连客户端、枚举工具并完成一次受支持调用。Windows/Linux/WSL 的条目是待验配置，不继承另一台电脑的可用状态。MCP 配置不得同步真实密钥。

## 示例技能

examples/ 下的纯方法与 Git CLI 技能展示格式。它们不自动安装，不属于另一位作者的产品集成。需要使用时由 Agent 在当前授权内复制到共享源、审阅、补齐本机链接。各示例说明自己的成功判据。
