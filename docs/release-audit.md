# v0.1.0 实施与审计记录

## 实施计划

1. 从已使用的共享体系提取四项原创治理核心、通用脚本和测试；在独立公开目录适配，原使用目录不变。
2. 用中性模板替换真实记忆、状态、复盘记录和安装清单；不打包第三方技能库、凭据或本机运行环境。
3. 补齐 macOS、Windows、独立 Linux、WSL 的部署说明、预览后接入工具和依赖文档。
4. 发布默认英文、关键介绍中英对照并可切换中文的 README、带五类 Agent 图标的四系统架构图、示例技能及客观对比。
5. 执行隔离测试、模板和链接检查、来源与许可证检查；通过后提交公开源码及版本 ZIP。

## 七个审计角度

| 角度 | 检查与修正 | 结论边界 |
|---|---|---|
| 体系一致性 | 区分共享来源、本机入口、Agent 原生配置与运行时；四项核心相互转交 | 文件规则不能替代宿主权限体系 |
| 跨系统 | 独立 Linux 单列；WSL 说明发行版、挂载与本机依赖；不硬编码 iCloud 路径 | 三平台隔离自动化通过；桌面客户端与 WSL 实机待验 |
| 开箱接入 | 一次接入 skills、memories、mcp；预览、保留同名私有目录、重复执行、按来源卸载 | 需 Python、用户核对实际 Agent 发现目录 |
| 内容和隐私 | 空白个人模板；虚构 Atlas 示例；无真实会话、账号状态和凭据 | 模式扫描不是完整安全保证 |
| 维护和扩展 | 纯方法 / CLI / MCP 示例与说明；新增技能补齐发现入口；个人内容升级保留 | 外部工具按需逐机安装 |
| 多端及团队 | 同步工具可替换；成员独立账号；协调同文件写入；区别断网读取与模型联网 | 无细粒度 ACL、数据库事务或分布式锁 |
| 对外表述 | 腾讯静态源码按固定提交引用；比较适用条件和维护成本 | 未部署腾讯、未进行效果或成本基准测试 |

## 修正的实际问题

- 首次入口同时接入技能、记忆和 MCP，避免只有技能可见。
- 原可选 MCP 的集成检查改用测试夹具，不要求用户安装扩展。
- 缺失的本机依赖参考已补齐；部署在同步源外创建 Python 环境。
- 发布模板的 lint 明确允许三份个人示例页，初始化补缺失文件，不覆盖个人正文。
- 核心项目路由取消对私人专家库、模型清单和其他未发布技能的强依赖。
- 同名私有目录或父目录指向其他共享源时停止；失败回滚本次新建链接。

## 本地验证

维护环境：macOS，Python 3.14.6。测试在临时源码副本和临时用户目录中运行，不修改维护者原有 Agent 入口。

最终测试数量和命令见本记录末尾的验证结果。链接和模板检查通过，仍需使用者在真实 Agent 中完成发现与调用验收。Windows、独立 Linux 的隔离自动化测试已在 GitHub runner 通过；桌面客户端与 WSL 未做实机验证。

视觉稿已检查桌面与移动窄屏渲染；GitHub README 使用独立 PNG，SVG 提供可编辑图源。图标来源与授权边界单独记录。

## 验证结果

- `python -B scripts/run_tests.py`：179 项测试，178 项通过，1 项按平台条件跳过。
- `python -B scripts/check.py`：语法、JSON、中性模板、Markdown 相对链接、双入口一致性、生成区同步及有界秘密/路径扫描通过。
- 隔离接入：预览不写入、技能/记忆/MCP 入口创建、重复运行、Atlas 查询、私有冲突保留、失败回滚及仅卸载匹配链接通过。
- 架构 PNG/SVG 和说明 HTML：桌面与窄屏检查完成。
- 未验证：真实 Agent 新会话发现、Windows/WSL/独立 Linux 实机、跨设备实际同步和腾讯运行效果。
