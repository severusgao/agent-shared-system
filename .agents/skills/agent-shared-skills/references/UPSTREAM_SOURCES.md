# Sources and third-party boundaries

The public core is maintained by Agent Shared System contributors. No installed private skill inventory, original chat history or user-specific approval receipts are included.

Optional third-party extensions keep their own license and pinned source/version. Publish only the material whose redistribution terms have been verified; preserve attribution and local adaptations. A public repository without a license is not permission to redistribute it. See [extensions](../../../../docs/extensions.md) and [source manifest](../../../../docs/source-provenance.json).
