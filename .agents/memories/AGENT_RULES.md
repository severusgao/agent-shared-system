# Agent Rules

## Shared Memory Role

Maintain approved stable context with provenance; native Agent memory may coexist. Do not store full chats or secrets here.

## Approval Required

Formal updates require authorization covering target and kind of change. Explicit design-and-implementation authorization continues across necessary steps; do not ask again for routine execution. Respect a user's discussion-only or preview-first boundary. Re-read targets before writing.

## Evidence-First Behavior

Distinguish user confirmation, observation and inference. Preserve conditions, exceptions and negative statements. Verify live paths and installations on the current host.

## Evolution Audit Gate

Review a repeated or clearly costly reusable issue against existing coverage. A proposal or completed audit is not approval. Apply only within current authorization.

## Task Scope And Editing

Use the simplest adequate method, keep changes focused and validate the intended result.

## Authority And Conflict Handling

The host's actual instruction hierarchy and the user's current scope apply. These file conventions do not override them.
