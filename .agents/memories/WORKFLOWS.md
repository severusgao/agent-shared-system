# Workflows

## Use Shared Memory

Run the relevance gate, read INDEX.md, select current sections, then query current text and reviewed history when needed. Expand truncated results and verify provenance.

## Propose Memory Update

Identify the reusable difference and sources; preserve conditions and inspect existing coverage. Use the current write policy and authorization.

## Apply Approved Update

Re-read target baselines, apply only the authorized difference, update relevant provenance/change records and run the memory lint. Other platforms remain unverified until tested.

## Agent Evolution Audit

Evidence → candidate → review/authorization → implementation → verification → later effect check. Multiple Agents repeating one source do not constitute independent evidence.
